# Local fonts

`src/styles/fonts.css` loads the committed files in this directory so the
desktop application renders consistently without network or system fonts.

## Files to place

| File | Weight | Source |
|---|---|---|
| `InterVariable.woff2` | variable, 100–900 | [Inter](https://github.com/rsms/inter) — `Inter Web/InterVariable.woff2` in the official release archive |
| `JetBrainsMono-Regular.woff2` | 400 | [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) — `fonts/webfonts/JetBrainsMono-Regular.woff2` |
| `JetBrainsMono-Medium.woff2` | 500 | [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) — `fonts/webfonts/JetBrainsMono-Medium.woff2` |
