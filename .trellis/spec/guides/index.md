# Cross-package thinking guides

> Pointer layer — the project's own docs system owns all facts.

- First-principles / architecture decisions: `AGENTS.md` rules 3–5; skill
  `first-principles`.
- Doc-vs-code conflicts: reconcile per `docs/README.md` (fix the stale side,
  record the verdict in `docs/STATUS.md`; never leave them unresolved).
- Before release work: `docs/STATUS.md` Open defects + Open items are the
  live gap list; the `rainy-day-attack` skill stress-tests designs.
